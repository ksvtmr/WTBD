# План работы команды на хакатоне

Расчёт на ~6 часов. Последние 20% времени — сборка и репетиция (по уставу команды). Сверка каждые 30 минут: готово / дальше / нужна помощь.

| Время | Кто | Что |
|---|---|---|
| 0–10% | Все (ведёт Теймур, фиксирует Ділнәз) | Разбор кейса, главный тезис: «стадия 0 на 90 дней, не закупать, не выбирать площадку сейчас» |
| 10–55% | Нұрайлы | Стейкхолдеры, ответы на 6 входящих документов, реестр «факт / заявление / допущение» → `01_analiz.md` §2, §7 |
| | Жанель | Площадки A/B/C, баланс потоков, сценарии цены → `01_analiz.md` §3–5 |
| | Ділнәз | План 90 дней, вехи, бюджет 750 млн ₸, RACI → `03_plan_90_dney.md` |
| | Даниал | Риски, проверка лимитов и сроков → `04_reestr_riskov.md`, `01_analiz.md` §6 |
| | Теймур | Устав проекта, итоговое решение для заказчика → `02_ustav_proekta.md` |
| | Алина | Сюжет и слайды → `05_vystuplenie_i_voprosy.md` |
| 55–80% | Алина собирает, остальные проверяют цифры друг друга | Финальные слайды, источники APA |
| 80–100% | Все | 2 репетиции с таймером (6:00), тренировка вопросов жюри, сдача |

Черновики готовы в этой папке: задача команды — проверить, адаптировать под себя и уметь объяснить каждую цифру.
